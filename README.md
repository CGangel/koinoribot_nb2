# Koinoribot NB2 使用说明

Koinoribot NB2 是基于 NoneBot2 的综合娱乐插件包，主插件入口会自动加载 `plugins/` 目录下的子插件。当前 README 只说明本仓库中已启用、可使用的功能。

下文命令示例默认省略 NoneBot 命令前缀。若你的 Bot 配置了 `/`、`#` 等前缀，请按实际配置发送，例如 `/签到`、`#钓鱼`。

## 功能概览

- 签到、钱包、金币排行榜、UID 查询与跨平台账号绑定
- 炒股、转账、低保、红包、幸运游戏与幸运转盘
- 新版钓鱼（单抽、品种/稀有度/级别/长度、图鉴、水族箱养成，框架阶段）与漂流瓶（已与钓鱼解耦）
- 宠物养成、扭蛋、宠物商店、技能、进化、誓约、排行榜
- 飞升之路、修炼、突破、修仙商店与升仙榜
- AI 画图、AI 修图、今日少女设定与人设图
- 猜单词、猜数字、猜日语、24 点小游戏
- 吃什么：公共菜单加个人专属菜单随机抽签，附节日与疯狂星期四提示
- 鲁迅说、莎士比亚说、自定义称呼、晚安
- SU 注册与公网白名单领养/审核

## 安装与加载

1. 将 `koinoribot_nb2` 放入 NoneBot2 项目的插件包目录中。
2. 安装依赖：

```bash
pip install -r requirements.txt
```

3. 在 NoneBot2 项目中加载本插件包。按你的项目包名调整导入路径，例如：

```python
nonebot.load_plugin("plugins.koinoribot_nb2")
```

如果你的项目使用 `nonebot.load_plugins()` 或插件目录自动加载，也可以按项目现有方式加载。加载主插件后，`plugins/` 下的子插件会由 `koinoribot_nb2.__init__` 自动加载。

## 配置

除超级用户外的全部配置存储在 `src/database/koinoribot.db` 的 `config` 表中，启动时一次性加载进内存。历史版本使用的 `koinori_config.py` 文件会在首次启动时自动迁移入库并删除。

### 配置面板（/config）

- 启动后可通过 `http://<ip>:<驱动端口>/config/` 网页修改全部配置项，保存后立即生效（写库并同步内存，无需重启）。面板挂载于驱动端口（与 OneBot ws 共用），不单独监听端口。
- 面板按模块分区，每个模块一个子页（左侧导航切换）；集合类配置（嵌套结构或条目较多，如鱼品种表、商店商品表）提供二级编辑子页，可逐条增删改。
- 面板需要密码登录，密码保存在 `koinoribot_nb2/passwd.py` 的 `PANEL_PASSWORD`（首次启动自动按模板生成随机密码，请打开文件查看并妥善保管）。
- 防爆破：同一 IP 10 分钟内密码错误 5 次将锁定 15 分钟。
- 等级为 0 的 SU 可在聊天中发送 `冰祈配置` 获取面板地址。

### passwd.py

仓库只保留 `passwd.py.template` 模板；启动时若本地不存在 `passwd.py` 会自动创建（`SUPERUSERS` 沿用模板默认值，`PANEL_PASSWORD` 为随机值）。`passwd.py` 已加入 `.gitignore`，请勿提交到仓库。

常用配置项（均可通过面板修改）：

- `qqbot_appid`、`qqbot_openid_api`：官方 QQBot 用户昵称/头像查询。
- `superusers`：最高权限 SU（等级 0）的统一 UID 列表，保存在 `passwd.py`，不在 config 表中。
- `blackusers`：冻结用户 UID 列表。
- `dibao`、`gold_max`、`transfer_fee`、`min_rest`：经济系统参数。
- `throw_cool_time`、`salvage_cool_time`、`comment_cool_time`、`bottle_price`、`comment_price`、`bottle_craft_starstone`、`bottle_salvage_starstone`：漂流瓶参数（扔/捡/评论冷却、金币价、合成与捞取的星星价），修改冷却需重启生效。
- 新版钓鱼**全部数值**都在配置面板可改，以当前数值为默认：
  - `fish_species`（品种表：基准长度= D 级最小长度、基准售价、基础空军概率、art 插画，可增删）
  - `fish_rarity_weights` / `fish_rarity_grade_weights`（稀有度权重、各稀有度级别权重）
  - `fish_grade_ranges`（各级别长度区间系数） / `fish_sell_price_exponent`（售价指数）
  - `fish_lucky_tiers`（放生幸运币分档） / `fish_cast_cd`（冷却） / `fish_limit_count`（每日次数） /
    `fish_auto_sell_threshold`（自动处理阈值）
  - `fish_shop_rods/lines/baits`（商店商品表，含 `desc` 描述；条目固定不可增删、名称锁定，
    条目内的 `grade_weights`/`rarity_weights` 键即级别/稀有度名，同样固定）
  - `fish_orb_name/price/desc` + `fish_orb_lucky_bonus` / `fish_orb_upgrade_base_price` /
    `fish_orb_max_level` / `fish_orb_energy_cap_base` / `fish_orb_cap_reduce_per_level` /
    `fish_orb_lucky_min_rarity` / `fish_orb_lucky_min_grade`（幸运宝珠，单件）
  - `fish_aquarium_daily_growth_cm` / `fish_slot_base_price` / `fish_growth_cap_factor`
    （水族箱；槽位固定 10/20，不可配置）
  - `fish_pump_name` / `fish_pump_price` / `fish_pump_desc` / `fish_pump_growth_bonus`
    （氧气泵，单件被动：成长速率加成，幸运币计价）
  价格区间：普通 100-2000 / 稀有 2000-4000 / 史诗 5000-10000 / 传说 20000-100000 /
  神话 100000-1000000。修改后立即生效。
- `gpt_image_api_key`、`gpt_image_api_base_url`、`gpt_image_model`、`gpt_image_response_format`：AI 画图/修图接口配置；图片返回格式可设为 `url` 或 `base64`/`b64_json`。
- `draw_cost`、`daily_limit`、`ai_draw_enable`、`enable_gold_aidraw`、`ai_draw_size`、`shaojo_image_size`、`aidraw_quality`、`aidraw_high_quality`：画图消耗、日限、开关、尺寸与质量。
- `public_bot`、`permit_bot`、`ip_address`：公网白名单模式配置。

数据会自动写入 `src/database/koinoribot.db`。图片、字体等静态资源位于 `src/img` 和 `src/fonts`。

## 通用说明

- UID 是插件内部统一账号 ID，用于跨 OneBot V11 和 QQBot 保存金币、背包、宠物等数据。
- `注册验证码` 仅支持私聊使用。获取验证码后，到另一个平台发送 `绑定账号 <验证码>`，并按提示选择保留哪个 UID。
- SU 权限分为 level 0、level 1 和 level 2。`passwd.py` 的 `SUPERUSERS` 中的 UID 视为 level 0；`注册su` 根据激活码类型注册为 level 1 或 level 2。
- 标注“SU”的命令需要 SU 权限。部分管理命令仅 level 0 可用。
- AI 画图和 AI 修图支持 OneBot V11 和 QQBot 侧使用。
- 红包、24 点、领养云冰祈等功能仅支持群聊场景。

规则要点：

- 每日钓鱼次数有限（`fish_limit_count`，默认 10 次），等级 0 的 SU 不受限制；
  宠物技能与幸运转盘可获得额外次数（转盘每次 1-10 次）；未实际抛竿
  （有待处理鱼获、渔具损坏等）不消耗次数
- 钓获后必须立即选择 卖鱼 / 放生 / 放入水族箱 之一，未处理前无法继续钓鱼
- 官Bot 平台：钓获卡片以**单条消息**发送（markdown 内嵌卡片图 + 底部两行按钮
  键盘：卖鱼/放生(如有)/放入水族箱 + 查看水族箱/自动处理开关）。所有按钮仅
  响应钓上这条鱼的玩家（触发者）的首次点击，非归属者或重复点击静默忽略
  （interaction 回调仍自动应答止转圈，合法点击被动回复结果并带 @点击者；
  查看水族箱按钮回复水族箱卡片图）。内嵌图依赖 `ip_address` 临时图床，未配置时降级
  为「图片 + 按钮」两条消息
- 钓鱼响应展示 长度/售价/幸运值/可成长至(成长后售价与幸运值)/品质，
  末行给出处理选项；售价 <1万 的鱼幸运值为 0，无法放生也不显示放生选项
- 放生不获得金币，按售价分档获得幸运币：<1万 0（不可放生）、1-5万 1、
  5-10万 2、10-100万 5、≥100万 10
- 鱼分品种（5 档稀有度：普通/稀有/史诗/传说/神话，共 36 种——前四档各 8 种、
  神话 4 种；图鉴与配置面板均按稀有度排序）、级别（D/C/B/A/S/X）与长度；
  每个品种有自己的基准长度（D 级最小长度）、基准售价与基础空军概率，均可单独配置
- 级别决定长度区间：D [基准,×1.2)、C [×1.2,×1.4)、B [×1.4,×1.6)、
  A [×1.6,×1.9)、S [×1.9,×2.2)、X [×2.2,×3)
- 可成长至 = 钓获时长度 × 成长上限系数（`fish_growth_cap_factor`，默认 1.5，可配置）
- 空军：最终空军率 =（品种基础空军率 − 总幸运值）/ 100（下限 0），
  基础空军率与幸运值均为百分点；**空军同样出卡片**（见下方“空军卡片”），
  展示跑掉的那条鱼与固定文案
- 钓到时按图鉴状态追加「图鉴已解锁！」「记录已更新：D→C！」
  「记录已更新：25cm→30cm！」等提示
- 图鉴奖励：每个稀有度各 6 档（全收集且全部品种历史最大级别 ≥
  D/C/B/A/S/X），共 30 档；`领取图鉴奖励` 一次领取全部达标档位，
  `查看图鉴奖励` 查看各档奖励与状态（传说/神话未全收集时内容显示 `???`）；
  查看图鉴时若有可领取档位，末尾（官Bot 双列图为右列末尾）会提醒。
  奖励内容可在配置面板热更新（`fish_collection_rewards`，档位键固定
  30 档不可增删改，格式 `{稀有度:级别档: {奖励: {奖励键: 数量}}}`，
  进入条目后在「奖励」块内增删改行即可调整奖励内容，单档可含多项；
  奖励键为**中文下拉选择**：金币/幸运币/宝石/幸运宝珠/氧气泵/
  每日钓鱼次数上限/SU激活码获取权限，以及按类别带名的商店商品
  （如「鱼饵·秘制鱼饵」「鱼竿·碳纤维鱼竿」「鱼线·大师鱼线」）；
  非消耗品数量强制 1）。发放时若已拥有该非消耗品（鱼竿/鱼线/宝珠/氧气泵）
  按售价折算为对应货币；fish_limit（每日钓鱼次数上限）与 su_code
  （SU 激活码获取权限，即开放 `获取激活码` 指令）领取后永久生效
- 级别概率由鱼竿给出（如初始竿 D60/C20/B14/A5/S1、四级竿 D30/C25/B25/A10/S6/X4），
  稀有度概率由鱼饵给出（如初始饵 普通65/稀有29/史诗5.75/传说0.25）
- 售价 = 基准售价 × 1.8^(出售时长度/基准长度)，水族箱养大后卖出更值钱
- 商店鱼竿/鱼线有耐久，每次钓鱼 -1，归零需修复；修复价按损耗比例计算：
  修复价 ×（最大耐久 − 当前耐久）/ 最大耐久；初始鱼竿/鱼线无限耐久
- 商店鱼饵为一次性用品，每次钓鱼消耗 1 个；初始鱼饵无限使用
- 三件装备**各管一条、互不重叠**：鱼竿决定级别概率（级别越高鱼越长，
  即大鱼概率）、鱼线提供幸运值（抵扣空军）、鱼饵决定稀有度概率；
  某级别内的长度完全由随机数决定
- 非鱼饵商品（鱼竿/鱼线/幸运宝珠）限购一次，买后自动装备，商店中显示
  已购买；商店商品表、稀有度权重、级别区间、图鉴奖励档位的**条目固定**：
  不可新增/删除/改名（只能改各自属性与价格，面板与后端双重强制）；
  商店条目内嵌的 `grade_weights`/`rarity_weights` 键即级别（D/C/B/A/S/X）
  与稀有度名，**同样固定**，只能改权重数值，商品可展示各自描述（`desc`）
- 幸运宝珠：唯一单件装备（不可卸下、无耐久），只能购买获得并自动装备；
  每成功钓鱼一次（不含空军）能量 +1，能量满后**下一次**钓鱼触发幸运暴击——
  只出限定稀有度/级别以上的鱼、并额外获得幸运值（注意：暴击那一竿若
  空军，能量已消耗、本次不产出，属刻意设计）。暴击时的概率在子集内按
  原比率归一化换算（如 A/S/X = 7%/2%/1% → 70%/20%/10%）；升级花
  幸运币，价格 = 基础价 × 升级前等级。名称/价格/描述与全部数值均可在
  配置面板修改
- 图鉴按品种统计历史最大级别与长度；历史最大长度只按钓获时长度统计，水族箱养成不回写
- 水族箱养成无需照料，鱼每天固定成长若干厘米（按时间戳连续折算，购买氧气泵后速率提升）；每日成长厘米数
  可配置；槽位固定初始 10、上限 20（不可配置，与卡片 4 列 × 5 行网格一致），
  第 n 个槽位价格 = 基准价 × 2^(n-10)
- 钓到鱼的响应是一张**卡片图**（无边框底图 + PIL 粘贴文本/插画，非纯文本；
  底图整幅铺满、无外圈描边与投影）：
  左侧鱼线下方是品种插画（`art` 字段，URL/本地路径；36 个品种各有一张
  透明背景 PNG，见 `src/img/fish/art/`，由 `assets/build_fish_art.py`
  生成），插画四周透明留白会被裁掉、等比缩放后水平居中且上缘贴住鱼线
  末端（鱼像挂在鱼线上）；下方鱼名、长度、图鉴状态章，左栏底部为幸运
  宝珠信息（积攒度「幸运宝珠 63/90」/ 满能量预告 / 本次暴击提示，
  未拥有宝珠时不显示）；
  中间稀有度/等级（各档位有专属色：稀有度灰/蓝/紫/橙/红，等级 D→X 灰/绿/
  蓝/紫/橙/红）、售价、幸运值、可成长至（含成长后售价与幸运值）；
  右侧处理选项与今日剩余次数
- 卡片底图按稀有度换主题色（仅上方横幅变色，其余底色不变）：
  普通-灰白、稀有-蓝、史诗-紫、传说-橙、神话-红
- 售价 <1万 的鱼无幸运值：卡片不显示幸运值栏，也不显示「放生」选项
- **空军卡片**：与正常钓获同一套布局与信息栏，改用空军底图变体——
  左栏不画鱼线、改为鱼左侧的几道波浪线（示意鱼挣脱逃走），右栏不画
  三个选项按钮、改贴固定文案「很可惜呢，/ 下次再试试吧」；左栏缩略图
  下方仍显示鱼名/大小/等级，再下方改为固定文案「鱼线被挣断，鱼逃走了...」
- 卡片渲染或发送失败时自动回退为原文本响应（品种 art 以合并转发发送图片）
- **水族箱卡片**（`查看水族箱` 指令与卡片按钮共用，见
  `plugins/fish/aquarium_card.py`）：表头带（标题 + 已用/已购槽位）+ **单列表格**
  （每行一条鱼，竖向排序，最多 20 行 = 槽位上限）+ 表尾提示带（4 行）。一行
  字段名，每条鱼一行 6 列，格式为
  `[等级]名称 | 稀有度 | 长度(cm) | 售价(金币) | 幸运值 | 成长所需时间`，其中长度/售价/
  幸运值均为 `当前值(max: 上限)`，末列按当前成长速率给出剩余时长
  （`N天N时`/`N时N分`/`N分`，已养满显示「已长至最大」）；行距紧凑，单列使卡片
  接近方形。表尾四行依次为：单条出售/放生提示、批量指令
  （出售小鱼/一键出售/一键放生）、氧气泵加成、扩展价格与空槽位/未解锁概况。
  与钓鱼卡片同一套路：几何装饰来自预渲染底图
  （`src/img/fish/aquarium_card.png`，由 `assets/build_aquarium_card.py`
  生成，底图分表头带/字段名条/一条数据行条/表尾带四段，渲染时按条数重复行条；
  列宽由字体实测宽度算出并导出到槽位表），坐标/字号/列宽与配色在
  `assets/aquarium_card_slots.json`，本模块只贴文字；**高度随条目数增长、不预留
  空行**，空箱时仅表头 + 一行提示。**量化用显式调色板**（背景自适应取色 26 色 +
  每种文字色及其 4 档渐隐写入调色板）：小字彩色若交给按面积的自适应量化会被
  合并掉（实测「史诗」变青蓝、「神话」变棕），显式调色板保证史诗=紫、
  神话/X=红等档位色保真。20 条各不相同的最坏情况约 42KB（<50KB）；失败回退文本面板
- 钓鱼帮助 / 钓鱼商店 / 图鉴 的长文本以伪造合并转发
  消息发送（官Bot 平台自动转为图片），避免刷屏；目前仅图鉴在官Bot

## 常见流程

### 跨平台绑定

1. 在账号 A 私聊发送 `注册验证码`。
2. 在账号 B 发送 `绑定账号 <验证码>`。
3. 按提示回复 `1` 或 `2`，选择保留哪个 UID。

### 发红包

1. 群内发送 `发红包 1000 5`。
2. 群成员发送 `抢红包` 领取。

### 宠物养成起步

1. 发送 `买宝石 10`。
2. 发送 `宠物商店` 查看可购买物品。
3. 发送 `购买 普通扭蛋 1`。
4. 发送 `开启 普通扭蛋`。
5. 抽到宠物后发送 `领养宠物 <名字>`。

### 修仙起步

1. 先在宠物系统完成 `永恒誓约`。
2. 发送 `宠物飞升` 推进飞升进度。
3. 飞升成功后通过 `修炼`、`突破`、`幸运突破` 提升境界。
4. 发送 `渡劫飞升` 尝试最终飞升。
